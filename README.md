## 项目介绍

该项目主要是基于https://github.com/easy-temps/vue3-vant-mobile 原项目，在此基础上进行了一些优化和调整，使其更适合开发。

## 分支

- main 主要用用于拉取https://github.com/billytmac/new-vue3-vite-template最新代码,方便其他分支跟它比较
- custom 根据main进行个性化调整

## Usage

### Development

Just run and visit <http://localhost:3000>

```bash
pnpm i

pnpm dev
```

### Build

To build the App, run

```bash
pnpm build
```
